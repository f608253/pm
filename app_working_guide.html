Technology Stack & Architectural Decisions

Detailed engineering justification for choices made across Frontend, Backend, and Database layers.

Frontend: Next.js + React 19 SSG / Export

Why Next.js (`output: 'export'`): Enables Static Site Generation (SSG), exporting pure HTML/CSS/JS files directly to /srv/static. This allows FastAPI to serve the entire application, eliminating Node.js container overhead in production deployments.

  • Zero Node.js server overhead in runtime.
  • TypeScript strictly typed board schemas.
  • @dnd-kit PointerSensors with 6px drag activation constraint.
  • Namespaced DnD IDs (c{id} and d{id}).
Backend: FastAPI + Python 3.11 Sync Threadpool

Why FastAPI Synchronous Handlers: Route handlers are standard def functions executed inside FastAPI's anyio worker threadpool. This isolates blocking SQLite disk I/O operations from interfering with asyncio event loops.

  • SQLAlchemy 2.0 Declarative Mapped models.
  • Explicit selectinload eager serialization preventing DetachedInstanceError.
  • Pydantic v2 input validation & schema generation.
  • In-memory bearer session store.
Database: SQLite + Alembic Embedded DB

Why SQLite (`kanban.db`): Zero-configuration embedded database stored at /data/kanban.db. Enforces foreign key constraints via engine connect hooks and uses integer positions for zero-gap card ordering.

  • PRAGMA foreign_keys=ON listener on connection.
  • Alembic automated schema migration pipeline.
  • Sequential positional re-indexing on card moves.
  • Cascade deletes on board/column removal.

Complete Function Reference Engine

Detailed breakdown of signatures and working logic for functions across backend and frontend.

load_board(db, board_id, user_id) backend/app/kanban.py

Fetches a board by ID from SQLAlchemy. Validates that the board's user_id matches the requesting user. Raises HTTP 404 if missing or HTTP 403 if unauthorized.

move_card(db, card, target_column_id, position) backend/app/kanban.py

Calculates sibling arrays for source and target columns. Re-indexes card positions starting from 0 to eliminate positional gaps across columns.

chat_with_board(board, question, history) backend/app/services/ai.py

Formats system prompt, board JSON snapshot, and conversation history. Sends to OpenRouter API (`openai/gpt-oss-120b`) and parses JSON output containing text response and board operations.

apply_operations(db, operations, user, board_id) backend/app/services/board_ops.py

Iterates through proposed AI operations (add, edit, move, delete). Validates ownership and input limits. Mutates database state and returns lists of applied and skipped operations.

hash_password(password) backend/app/security.py

Generates a 16-byte random salt and computes a PBKDF2-SHA256 digest with 600,000 iterations. Returns formatted string pbkdf2_sha256$600000$salt$digest.

moveCard(columns, activeDndId, overDndId) frontend/src/lib/kanban.ts

Parses namespaced IDs (c{id}, d{id}), isolates active card, removes it from source column, and inserts it at target index in destination column for optimistic UI updates.

request<T>(path, init) frontend/src/lib/api.ts

Fetch API client wrapper. Automatically attaches Authorization: Bearer <token>, enforces cache: "no-store", and invokes 401 callback to redirect to login on session expiry.

fetch_ai_news(randomize) backend/app/services/ai.py

Fetches live RSS XML feed from TechCrunch AI category using httpx, parses elements with xml.etree.ElementTree, sorts by pubDate, and returns top 3 news items.

board_out(db, board_id) backend/app/serializers.py

Uses SQLAlchemy selectinload(Board.columns).selectinload(Column.cards) to materialize the entire board, column, and card entity tree before converting to Pydantic models.

card_intelligence(board, card_id, task) backend/app/services/ai.py

Executes specific LLM task for a card: generates markdown acceptance criteria, suggests card priority (high/medium/low), or scans all board cards to report duplicate tasks.

Interactive End-to-End System Flows

Visual step-by-step representation of key application workflows.

1. Drag and Drop Card Movement Flow

1
User Interaction & Activation
User clicks and drags a card. @dnd-kit PointerSensor checks distance constraint (6px). DragOverlay renders a preview clone of KanbanCardPreview.
2
Optimistic Frontend State Update
onDragEnd event fires. moveCard() in lib/kanban.ts calculates new card positions across columns. UI immediately updates React state for 0ms visual latency.
3
Async Backend Sync
Frontend calls PATCH /api/cards/{card_id} with target column_id and position.
4
Database Transaction & Re-ordering
Backend move_card() in kanban.py executes inside a SQLite transaction, re-numbering all sibling cards sequentially. If request fails, frontend state reverts to previous snapshot.

2. AI Assistant Natural Language Board Mutation Flow

1
Chat Prompt Submission
User types "Add a high priority task for API rate limiting to In Progress" in ChatSidebar.
2
Board Materialization & Context Assembly
FastAPI endpoint POST /api/ai/chat loads board, materializes JSON tree, closes read transaction, and fetches recent conversation history.
3
OpenRouter LLM Inference
Prompt sent to openai/gpt-oss-120b. Model returns JSON object containing conversational text reply and structured board operations array.
4
Transactional Execution
board_ops.apply_operations() validates user ownership and parameters, creates the card in SQLite, updates session history, and returns fresh board state to frontend.

REST API Specifications

Complete documentation of FastAPI REST endpoints.

Method Endpoint Path Auth Required Description & Response Model
POST /api/auth/login No Authenticates username/password, verifies hash, creates session token. Returns SessionResponse.
POST /api/auth/logout Yes Revokes active session token. Returns {"success": true}.
GET /api/boards Yes Returns list of board summaries (ID, Title) owned by current user.
GET /api/boards/{board_id} Yes Returns full board tree including columns and cards serialized via selectinload.
PATCH /api/cards/{card_id} Yes Updates card title, details, priority, target column ID, or index position.
POST /api/ai/chat Yes Processes natural language board query, executes operations, returns updated board state.
POST /api/ai/card-intelligence Yes Generates card acceptance criteria details, priority suggestions, or duplicate card detection.
POST /api/ai/workflow-optimization Yes Identifies column bottlenecks, next card actions, and optimal card reordering lists.
GET /api/ai/news Yes Fetches and parses live RSS AI tech news items from TechCrunch.
