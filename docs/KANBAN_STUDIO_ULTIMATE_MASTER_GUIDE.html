🚀 1. Product Vision, Core Platform Architecture & Executive Summary ARCHITECTURE

Kanban Studio is an enterprise-grade, single-board project management platform engineered to harmonize zero-latency task management with autonomous artificial intelligence assistance. Designed specifically around a single, highly refined Kanban board canvas, the system eliminates context-switching friction while integrating 10 specialized LLM intelligence tools powered by OpenRouter (openai/gpt-oss-120b).

┌─────────────────────────────────────────────────────────────────────────────────────────────┐ │ KANBAN STUDIO [Single Board Kanban Canvas] [ Signed in as User | Log out ] │ │ │ │ AI Analysis: [AI News] [Daily Summary] [Workflow] [Risk Assessment] [Effort Estimate] │ │ [Retrospective] [Standup] [Weekly Report] │ ├─────────────────────────────────────────────────────────────────────────────────────────────┤ │ ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐ ┌──────────┐ │ │ │ TO DO (+) │ │ IN PROGRESS (+) │ │ REVIEW (+) │ │ TESTING (+) │ │ DONE (+) │ │ │ ├─────────────────┤ ├─────────────────┤ ├─────────────────┤ ├─────────────────┤ ├──────────┤ │ │ │ Card Title │ │ Card Title │ │ Card Title │ │ Card Title │ │ Card... │ │ │ │ [AI] [P: High] │ │ [AI] [P: Med] │ │ [AI] [P: Low] │ │ [AI] │ │ │ │ │ └─────────────────┘ └─────────────────┘ └─────────────────┘ └─────────────────┘ └──────────┘ │ │ ┌──────────────────┐ │ │ │ Ask the assistant│ │ │ └──────────────────┘ │ └─────────────────────────────────────────────────────────────────────────────────────────────┘

Primary Architectural Innovation Pillars

  • Single-Container SSG + FastAPI Serving Paradigm: The React/TypeScript frontend (Next.js 15 App Router) is built as a static site export (output: 'export') producing static assets in /srv/static. FastAPI mounts these static files at / while handling REST JSON requests at /api/. This removes Node.js runtime memory overhead completely in production containers.
  • FastAPI Synchronous AnyIO Worker Execution: Database endpoints are defined using standard Python def route handlers rather than async def. FastAPI dispatches synchronous handlers into an anyio worker threadpool, preventing blocking SQLite disk I/O operations from freezing Python's asynchronous event loop.
  • Transactional AI Board Operations Engine: The AI co-pilot interprets natural language instructions (e.g., "Move the login bug card to In Progress and mark priority high") and outputs typed JSON board mutations (add_card, edit_card, move_card, delete_card). Each operation is validated against database ownership constraints before committing.
  • Deterministic Positional Re-Indexing Domain Logic: Both columns and cards maintain zero-based integer position attributes. Every creation, move, or deletion operation automatically triggers sequential re-indexing to ensure gapless indices (0, 1, 2...) and identical visual rendering across clients.

-- 1. Users Table
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username VARCHAR(64) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 2. Sessions Table (In-Memory / DB fallback)
CREATE TABLE sessions (
  token VARCHAR(64) PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 3. Boards Table
CREATE TABLE boards (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(120) NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX ix_boards_user_id ON boards(user_id);

-- 4. Columns Table
CREATE TABLE columns (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  board_id INTEGER NOT NULL REFERENCES boards(id) ON DELETE CASCADE,
  title VARCHAR(120) NOT NULL,
  position INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX ix_columns_board_id ON columns(board_id);

-- 5. Cards Table
CREATE TABLE cards (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  column_id INTEGER NOT NULL REFERENCES columns(id) ON DELETE CASCADE,
  title VARCHAR(200) NOT NULL,
  details TEXT NOT NULL DEFAULT '',
  priority VARCHAR(16) NOT NULL DEFAULT 'medium',
  position INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX ix_cards_column_id ON cards(column_id);

-- 6. Conversations Table (AI Chat Context)
CREATE TABLE conversations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  board_id INTEGER NOT NULL REFERENCES boards(id) ON DELETE CASCADE,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX ix_conversations_board_id ON conversations(board_id);

-- 7. Messages Table (AI Chat History)
CREATE TABLE messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id INTEGER NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
  role VARCHAR(16) NOT NULL,
  content TEXT NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX ix_messages_conversation_id ON messages(conversation_id);

from datetime import datetime
from sqlalchemy import DateTime, ForeignKey, Integer, String, Text, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    username: Mapped[str] = mapped_column(String(64), nullable=False, unique=True)
    password_hash: Mapped[str] = mapped_column(String(255), nullable=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp())

    boards: Mapped[list["Board"]] = relationship(back_populates="user", cascade="all, delete-orphan")

class Board(Base):
    __tablename__ = "boards"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"), nullable=False, index=True)
    title: Mapped[str] = mapped_column(String(120), nullable=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp())
    updated_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp(), onupdate=func.current_timestamp())

    user: Mapped[User] = relationship(back_populates="boards")
    columns: Mapped[list["Column"]] = relationship(back_populates="board", cascade="all, delete-orphan", order_by="Column.position")

class Column(Base):
    __tablename__ = "columns"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    board_id: Mapped[int] = mapped_column(ForeignKey("boards.id", ondelete="CASCADE"), nullable=False, index=True)
    title: Mapped[str] = mapped_column(String(120), nullable=False)
    position: Mapped[int] = mapped_column(Integer, nullable=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp())
    updated_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp(), onupdate=func.current_timestamp())

    board: Mapped[Board] = relationship(back_populates="columns")
    cards: Mapped[list["Card"]] = relationship(back_populates="column", cascade="all, delete-orphan", order_by="Card.position")

class Card(Base):
    __tablename__ = "cards"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    column_id: Mapped[int] = mapped_column(ForeignKey("columns.id", ondelete="CASCADE"), nullable=False, index=True)
    title: Mapped[str] = mapped_column(String(200), nullable=False)
    details: Mapped[str] = mapped_column(Text, nullable=False, default="")
    priority: Mapped[str] = mapped_column(String(16), nullable=False, default="medium")
    position: Mapped[int] = mapped_column(Integer, nullable=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp())
    updated_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, server_default=func.current_timestamp(), onupdate=func.current_timestamp())

    column: Mapped[Column] = relationship(back_populates="cards")

from sqlalchemy.orm import Session

from app.models import Board, Card, Column, User
from app.security import hash_password

DEFAULT_COLUMNS = ["Backlog", "Discovery", "In Progress", "Review", "Done"]

SEED_CARDS = {
    "Backlog": [
        ("Align roadmap themes", "Draft quarterly themes with impact statements and metrics."),
        ("Gather customer signals", "Review support tags, sales notes, and churn feedback."),
    ],
    "Discovery": [
        ("Prototype analytics view", "Sketch initial dashboard layout and key drill-downs."),
    ],
    "In Progress": [
        ("Refine status language", "Standardize column labels and tone across the board."),
        ("Design card layout", "Add hierarchy and spacing for scanning dense lists."),
    ],
    "Review": [
        ("QA micro-interactions", "Verify hover, focus, and loading states."),
    ],
    "Done": [
        ("Ship marketing page", "Final copy approved and asset pack delivered."),
        ("Close onboarding sprint", "Document release notes and share internally."),
    ],
}


def seed(db: Session) -> None:
    if db.query(User).first():
        return

    user = User(username="user", password_hash=hash_password("password"))
    db.add(user)
    db.flush()

    board = Board(title="Product Development", user_id=user.id)
    db.add(board)
    db.flush()

    for pos, col_title in enumerate(DEFAULT_COLUMNS):
        col = Column(title=col_title, position=pos, board_id=board.id)
        db.add(col)
        db.flush()

        cards = SEED_CARDS.get(col_title, [])
        for c_pos, (card_title, card_details) in enumerate(cards):
            card = Card(
                title=card_title,
                details=card_details,
                position=c_pos,
                column_id=col.id,
            )
            db.add(card)

    db.commit()
🔄 5. Deterministic Positional Re-Indexing Domain Logic KANBAN DOMAIN

To maintain visual consistency across clients without gaps in card ordering indices, backend/app/kanban.py implements a gapless integer re-indexing algorithm.

Card Re-indexing Lifecycle Flow: ───────────────────────────────────────────────────────────────────────────── 1. Card Move Initiated: Card (id=10) moved from "To Do" to "In Progress" at position 0 2. Source Column ("To Do"): - Card 10 removed - Remaining sibling cards re-indexed sequentially (0, 1, 2...) 3. Target Column ("In Progress"): - Sibling cards fetched ordered by position - Target list sliced: siblings[:0] + [Card 10] + siblings[0:] - Items sequentially re-assigned position = index (0, 1, 2...) 4. Transaction Committed: Deterministic gapless indices persisted. ─────────────────────────────────────────────────────────────────────────────

Full Python Re-Indexing Domain Module (backend/app/kanban.py)

backend/app/kanban.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models import Card, Column


def move_column(db: Session, column: Column, position: int) -> None:
    siblings = list(
        db.scalars(
            select(Column)
            .where(Column.board_id == column.board_id, Column.id != column.id)
            .order_by(Column.position)
        )
    )
    index = min(position, len(siblings))
    for idx, item in enumerate(siblings[:index] + [column] + siblings[index:]):
        item.position = idx


def move_card(db: Session, card: Card, target_column_id: int, position: int) -> None:
    source_column_id = card.column_id

    source_siblings = []
    if source_column_id != target_column_id:
        source_siblings = list(
            db.scalars(
                select(Card)
                .where(Card.column_id == source_column_id, Card.id != card.id)
                .order_by(Card.position)
            )
        )

    target_siblings = list(
        db.scalars(
            select(Card)
            .where(Card.column_id == target_column_id, Card.id != card.id)
            .order_by(Card.position)
        )
    )

    index = min(position, len(target_siblings))
    card.column_id = target_column_id
    for idx, item in enumerate(target_siblings[:index] + [card] + target_siblings[index:]):
        item.position = idx

    for idx, sibling in enumerate(source_siblings):
        sibling.position = idx

Full Python Board Operations Engine (backend/app/services/board_ops.py)

backend/app/services/board_ops.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.kanban import move_card
from app.models import Board, Card, Column, User

MAX_TITLE = 200
MAX_DETAILS = 4000


class OperationRejected(Exception):
    """Raised when a proposed operation fails validation or ownership constraints."""


def _column(db: Session, column_id: int, user_id: int, board_id: int) -> Column:
    column = db.scalar(
        select(Column)
        .join(Board)
        .where(Column.id == column_id, Column.board_id == board_id, Board.user_id == user_id)
    )
    if not column:
        raise OperationRejected(f"column {column_id} not found on this board")
    return column


def _card(db: Session, card_id: int, user_id: int, board_id: int) -> Card:
    card = db.scalar(
        select(Card)
        .join(Column)
        .join(Board)
        .where(Card.id == card_id, Column.board_id == board_id, Board.user_id == user_id)
    )
    if not card:
        raise OperationRejected(f"card {card_id} not found on this board")
    return card


def _text(val: object, limit: int, label: str) -> str:
    if not isinstance(val, str) or not val.strip():
        raise OperationRejected(f"{label} must be a non-empty string")
    clean = val.strip()
    if len(clean) > limit:
        raise OperationRejected(f"{label} exceeds limit of {limit} chars")
    return clean


def apply_operation(db: Session, op: dict, user: User, board_id: int) -> str:
    if not isinstance(op, dict):
        raise OperationRejected("operation must be an object")
    kind = op.get("type")

    if kind == "add_card":
        column = _column(db, op.get("column_id"), user.id, board_id)
        title = _text(op.get("title"), MAX_TITLE, "title")
        details = op.get("details") or ""
        card = Card(
            column_id=column.id,
            title=title,
            details=details[:MAX_DETAILS],
            position=len(column.cards),
        )
        db.add(card)
        return f'Added "{title}" to {column.title}'

    if kind == "edit_card":
        card = _card(db, op.get("card_id"), user.id, board_id)
        if op.get("title") is not None:
            card.title = _text(op.get("title"), MAX_TITLE, "title")
        if op.get("priority") is not None:
            card.priority = op.get("priority")
        if op.get("details") is not None:
            card.details = str(op.get("details"))[:MAX_DETAILS]
        return f'Updated "{card.title}"'

    if kind == "move_card":
        card = _card(db, op.get("card_id"), user.id, board_id)
        target = _column(db, op.get("column_id"), user.id, board_id)
        position = op.get("position", 0)
        move_card(db, card, target.id, position)
        return f'Moved "{card.title}" to {target.title}'

    if kind == "delete_card":
        card = _card(db, op.get("card_id"), user.id, board_id)
        title = card.title
        db.delete(card)
        return f'Deleted "{title}"'

    raise OperationRejected(f"unknown operation type {kind!r}")


def apply_operations(db: Session, operations: list, user: User, board_id: int) -> tuple[list[str], list[str]]:
    applied = []
    skipped = []
    for op in operations:
        try:
            msg = apply_operation(db, op, user, board_id)
            applied.append(msg)
        except OperationRejected as err:
            skipped.append(str(err))
    return applied, skipped

import hashlib
import os

ITERATIONS = 600000


def hash_password(password: str) -> str:
    salt = os.urandom(16)
    dk = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, ITERATIONS)
    return f"{salt.hex()}:{dk.hex()}"


def verify_password(password: str, hash_str: str) -> bool:
    try:
        salt_hex, dk_hex = hash_str.split(":", 1)
        salt = bytes.fromhex(salt_hex)
        expected_dk = bytes.fromhex(dk_hex)
        dk = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, ITERATIONS)
        return hashlib.compare_digest(dk, expected_dk)
    except Exception:
        return False

🎯 11. @dnd-kit Engine Calibration & Collision Prevention DRAG & DROP
  • Activation Constraint: PointerSensor initialized with activationConstraint: { distance: 6 } to ensure clicks on buttons or card titles don't trigger drag states.
  • Prefix Namespacing: Column IDs prefixed with c{id} and Card IDs prefixed with d{id} to prevent collision in @dnd-kit's global lookup registry.
  • Optimistic State Mutators: Local React board state in frontend/src/lib/kanban.ts updates instantly on drag-end before sending HTTP move requests.
🔒 12. Authentication Security & Bearer Token Management SECURITY

Session management uses cryptographically secure tokens. On user login, secrets.token_urlsafe(32) generates a token mapping to the user session in memory:

backend/app/sessions.py
import secrets
from datetime import datetime, timezone

_sessions: dict[str, int] = {}


def create_session(user_id: int) -> str:
    token = secrets.token_urlsafe(32)
    _sessions[token] = user_id
    return token


def get_user_id(token: str) -> int | None:
    return _sessions.get(token)


def delete_session(token: str) -> None:
    _sessions.pop(token, None)
