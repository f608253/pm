3. Frontend & Backend Interaction

How the Next.js client communicates with the FastAPI server

In development, the Next.js dev server runs on port 3000 and proxies API calls to the FastAPI backend running on port 8000. In production, the FastAPI server directly serves the pre-compiled static files located in /srv/static and routes all /api/* requests to the REST controllers.

# Unified Production Request Flow

Browser Client ──► HTTP GET /api/boards ──► FastAPI ASGI Server (Port 8000)

├──► Matches /api/* router ──► SQLAlchemy 2.x Session ──► SQLite (kanban.db)

└──► Fallback catch-all route ──► Returns /srv/static/index.html (SPA Client Router)

Authentication is handled via Bearer tokens stored securely in browser localStorage. Every protected API request attaches an Authorization: Bearer <token> header, which is verified by FastAPI's dependency injection layer (backend/app/api/deps.py).

4. Database & ORM Architecture

Data models, relationships, migrations, and integrity

The backend uses SQLAlchemy 2.x with SQLite. SQLite requires explicit foreign key constraint activation upon every new connection, which is handled via connect event listeners: 

@event.listens_for(engine, "connect")
def set_sqlite_pragma(dbapi_connection, connection_record):
    cursor = dbapi_connection.cursor()
    cursor.execute("PRAGMA foreign_keys=ON")
    cursor.close()

Database migrations are fully managed by Alembic. When the application boots up, app.main.on_startup() executes init_database(), automatically running pending Alembic migrations and seeding initial test data if the database is empty.

6. Production Deployment & Operations

Why this is a production deployment, not a development setup

Unlike development mode where hot-reloading dev servers run on ports 3000 and 8000 with unminified assets and memory leaks, this deployment architecture is built for production environments:

Multi-Stage Docker Build

The frontend is compiled into optimized static HTML/JS/CSS via Next.js static export in Node 24 alpine container, then injected into the production Python 3.12 slim image.

Persistent Volume Mounting

SQLite database is stored in an external Docker volume (./data:/data), guaranteeing that container restarts or updates never wipe user boards or task history.

Zero Dev Overhead

No Node.js runtime is present in the production container. FastAPI serves optimized static files directly at lightning speed with Uvicorn worker process.

Automatic Restart Policies

Configured with restart: unless-stopped in Docker Compose to ensure 24/7 uptime across system reboots or transient server crashes.

7. Restart & Maintenance FAQ

Do we need to restart both frontend and backend after changes?

Question: After making changes, do we need to restart both frontend and backend?

Short Answer: In production (Docker), because the frontend is compiled into static assets and bundled directly inside the backend container image, any frontend or backend code change requires rebuilding and restarting the Docker container so the static export and Python code are updated.

Commands to rebuild and restart: 

./scripts/start.sh   # Or docker compose up --build -d

8. Security & Hardening

Authentication, CORS, and data protection measures

Kanban Studio implements strict security guardrails across its stack:

  • Strict CORS Middleware: Configurable via ALLOWED_ORIGINS environment variable.
  • Token-Based Auth: Secure bearer tokens validated against persistent database sessions.
  • Foreign Key Enforcement: SQLite PRAGMA enforcement guaranteeing relational integrity.
  • Scoped AI Operations: Board operations strictly validated against owner IDs and target boards to prevent cross-board data corruption.
