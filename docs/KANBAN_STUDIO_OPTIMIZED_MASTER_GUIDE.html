SECTION 01

Executive Summary & Core Platform Vision

Kanban Studio is an enterprise-grade, AI-native single-board project management platform. Designed around a single, highly refined Kanban board paradigm, Kanban Studio provides zero-latency drag-and-drop workflow tracking alongside an AI co-pilot powered by Large Language Models via OpenRouter (openai/gpt-oss-120b).

🚀 Static Export & Fast Mount

Next.js 15 exports static HTML/JS/CSS assets (output: 'export') served directly by FastAPI from /srv/static. Zero Node.js runtime container overhead.

⚡ AnyIO Threadpool Execution

Synchronous FastAPI route handlers execute in AnyIO worker threads, isolating blocking SQLite disk I/O from Python's asyncio event loop.

🤖 Transactional AI Engine

LLM interprets natural language queries into structured JSON mutations (add_card, edit_card, move_card, delete_card) verified with ownership rules.

💡 Deterministic Positional Re-indexing Algorithm

Columns and cards maintain explicit integer position fields. Every mutation automatically re-indexes items sequentially (0, 1, 2...) to eliminate index gaps and guarantee deterministic visual ordering across sessions.

Technology Stack & Architectural Decision Matrix

2.1 Frontend Engineering

Layer Selected Technology Rationale & Engineering Impact
Framework Next.js 15 (App Router) Static Export (output: 'export') places pre-rendered HTML/JS into /srv/static. Zero Node.js runtime memory consumption in production containers.
UI Runtime React 19 & TypeScript Guarantees strict end-to-end type safety across board models, API payload trees, component props, and drag events.
Drag & Drop @dnd-kit (Core & Sortable) Calibrated PointerSensor with 6px drag activation constraint. Uses prefix namespacing (c{id} columns, d{id} cards) to prevent ID collisions.
Styling Tailwind CSS Dark glassmorphism palette using custom theme CSS variables (--navy-dark, --primary-blue, --accent-yellow).

2.2 Backend & Database Architecture

Layer Selected Technology Rationale & Engineering Impact
API Engine FastAPI (Python 3.11+) Sync route handlers (def) running in AnyIO threadpool avoid async ORM driver overhead and SQLite disk lock contention.
ORM Layer SQLAlchemy 2.0 Explicit selectinload trees build complete Pydantic model responses before returning, completely eliminating DetachedInstanceError.
Database Embedded SQLite 3 Stored at ./data/kanban.db. Foreign key constraints enforced on every connection via SQLAlchemy PRAGMA foreign_keys=ON listener.
Authentication PBKDF2-SHA256 & Bearer Tokens 600,000 hashing iterations with 16-byte random salts. 32-byte URL-safe session bearer tokens stored in memory.

SECTION 04

Complete REST API Endpoints Specification

Method Endpoint Path Auth Required Request Body / Parameters Response Description
POST /api/auth/register No {username, password} Creates user, seeds default board/columns, returns token.
POST /api/auth/login No {username, password} Validates credentials, returns bearer session token.
GET /api/boards/me Bearer Token None Returns user's board with eager-loaded columns & cards.
POST /api/columns Bearer Token {board_id, title} Appends new column to the right of the board.
POST /api/cards Bearer Token {column_id, title, details, priority} Creates new card in target column.
POST /api/cards/{id}/move Bearer Token {column_id, position} Moves card to target column and index with re-indexing.
POST /api/ai/chat Bearer Token {board_id, message} Sends query to LLM, executes transactional board mutations.
GET /api/ai/news Bearer Token ?randomize=true Fetches and parses TechCrunch AI RSS feed items.

AI Operations Engine & 10-Tool Productivity Suite

The AI system integrates 10 high-value productivity tools powered by OpenRouter (openai/gpt-oss-120b):

📊 Board-Wide Header Tools

• Daily Summary: Progress metrics & actionable suggestions.
• Workflow Optimization: Bottlenecks, next actions & optimal order.
• Risk Assessment: Identifies delivery risks in pending work.
• Effort Estimation: Assigns T-shirt sizes (S, M, L) with hints.
• Sprint Retrospective: What went well & process action items.
• Daily Standup: First-person talking points & blockers.
• Weekly Progress Report: Net impact and work categorisation.
• AI Tech News RSS: Live industry news with randomization.

🎴 Per-Card Intelligence Badge

• Generate Details: Drafts structured Markdown specs with checkable Acceptance Criteria.
• Suggest Priority: Evaluates title/details to recommend high, medium, or low priority.
• Detect Duplicates: Scans entire board to flag material overlap or exact duplicates.

SECTION 10

Security Hardening & Reliability Matrix

🔒 Security Architecture

• PBKDF2-SHA256 password hashing with 600,000 iterations & 16-byte random salts.
• 32-byte URL-safe cryptographic session bearer tokens.
• Explicit ownership checks on every database query preventing cross-user data leakage.
• Parameterized ORM queries preventing SQL injection attacks.

🛡️ Reliability & Failover

• Exponential backoff retries (up to 3 attempts) on OpenRouter AI calls.
• Transactional database rollback when AI operations fail verification.
• Foreign key enforcement listeners active on every SQLite connection.
• Automated positional re-indexing preventing visual card gaps.
